Methodology & data notes

Job Watcher queries anonymous JSON applicant-tracking-system endpoints. It does not scrape job-page HTML. All postings returned by each configured board are retained; JPMorgan Chase uses the required analyst search because its full board exceeds 5,000 jobs. This is a tracked-board inventory, not the whole labor market.

The backend’s title-only rule marks Finance & Banking Analyst families, including finance, FP&A, treasury, credit, banking and explicitly financial risk. The site reads in_role; it does not reclassify titles. Read the exact title rule.

GitHub Actions runs the pipeline daily. Compressed raw JSON is retained by UTC date; history.csv is rebuilt from raw files alone. Failed sources do not cause false removals, so open inventory may include a failed source’s last known postings. Counts include all roles unless labeled otherwise.

A source’s initial snapshot is a baseline: those jobs are not counted as new, and their actual opening dates are unknown. Removed means no longer returned by a later successful source scan; it does not necessarily mean a position was filled. Current history is not a full event ledger; a reappearance clears the earlier removal date. Citi and Walmart were excluded because complete coverage beyond Workday’s 2,000-result cap could not be proven.

Install from your browser’s app menu when supported; on iOS use Share → Add to Home Screen. Offline data becomes available after a successful load and service-worker activation. Browser storage may be cleared by the browser or device.
